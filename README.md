# Aplikasi_dapur_mbg
Aplikasi web untuk mendukung operasional dapur produksi makanan bergizi gratis (program MBG), mencakup pencatatan pemesanan bahan baku hingga penerimaan barang. Dibangun untuk membantu tim dapur di berbagai lokasi mencatat dan memantau proses harian secara digital, menggantikan pencatatan manual berbasis kertas.
